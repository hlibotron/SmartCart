# Category Images

Put default category photos in this folder. These images are used when a
specific product photo does not exist.

Supported formats:

- `.webp`
- `.jpg`
- `.jpeg`
- `.png`

Expected category file names:

- `dairy.png`
- `meat.png`
- `vegetables.png`
- `fruits.png`
- `drinks.png`
- `grocery.png`
- `other.png`

The public URL is:

```text
/uploads/category-images/{filename}
```
