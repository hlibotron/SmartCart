# Store Logos

Put store logo images in this folder. They are used in receipt lists, receipt
summary, and product price store rows.

Supported formats:

- `.webp`
- `.jpg`
- `.jpeg`
- `.png`

Recommended file names:

- `atb.png`
- `silpo.png`
- `novus.png`
- `auchan.png`

You can also use a normalized store name, for example:

- `сільпо.png`
- `атб.png`

The public URL is:

```text
/uploads/store-logos/{filename}
```
